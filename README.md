# 하이놀이터

어린이가 AI를 배우고 놀 수 있는 웹사이트입니다. → https://hiplayground.kr

## 무엇이 있나

- **콩콩이의 AI 교실**: 수업 10개. 다 마치면 인증서를 받고, 부모님과 함께 써 볼 수 있는 진짜 AI 링크가 열립니다.
- **AI 실험실**: 주간 도전, 이달의 실험, 도장판.
- **경제교실** (`econ/`): 코스 10개, 낱말 사전, 10년 투자·저축 게임.
- **추억의 오락실** (`games/`): 브라우저 게임 9종.
- **친구 점수판**: 별명으로 수업 별과 게임 최고 기록을 겨룹니다.

## 구조

빌드 과정이 없는 정적 사이트입니다. GitHub Pages로 배포하고 `CNAME`으로 도메인을 연결합니다.

```
index.html   입구·교실·실험실·점수판
econ/        경제교실
games/       오락실 게임 (01-block-stack ~ 09-cave-runner)
```
